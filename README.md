# MULTILINGUAL-AI-GUIDED-CIVIC-ISSUE-REPORTING-AND-GOVERNMENT-SERVICE-ASSISTANCE-SYSTEM
AI-powered multilingual platform for civic issue reporting, complaint management, and government service assistance, enabling citizens to interact with public services in their preferred language.
Quick Summary

The project develops an AI-powered multilingual platform that helps citizens:

Report civic issues (garbage, potholes, water leakage, street lights, etc.)
Access government services and welfare schemes
Communicate through text, voice, and multiple languages
Track complaints and applications in real time
Receive AI-guided assistance using NLP and chatbot technology
Technologies Used
Frontend: HTML, CSS, Bootstrap, JavaScript
Backend: Python Flask
Database: MySQL / SQLite
AI/NLP: Groq API, NLP Libraries, Speech-to-Text
Translation: Deep Translator
Modules
User Authentication
Voice & Multilingual Input
Civic Issue Reporting
AI-Based Complaint Classification
Government Service Assistance
Complaint & Application Tracking
Feedback & Notification System
